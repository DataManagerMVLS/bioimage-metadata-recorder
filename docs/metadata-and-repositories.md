# Metadata standards and repository readiness

This project aims to help capture bioimaging study, acquisition and analysis metadata using REMBI-aligned concepts.

## Review before claiming compliance

- Map each application field to an appropriate REMBI element, with version and citation.
- Record organism, sample, preparation, instrument, acquisition settings, channels and analysis provenance where applicable.
- Distinguish mandatory fields for this app from fields required by a particular repository submission workflow.
- Validate identifiers and ontology terms, including offline lookup failures.
- Test export structure against current BioImage Archive submission guidance.

The current prototype does not submit directly to BioImage Archive. No formal compliance assessment has yet been performed.
