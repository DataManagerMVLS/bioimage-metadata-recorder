# Licensing for bioimaging training materials

The project intends to use **Creative Commons Attribution 4.0 International (CC BY 4.0)** for **new, original, approved** hackathon training resources, including microscope-side stewardship checklists and role-specific bioimaging data management planning checklists.

**Approval required:** The actual authors and any institutional rights holders must agree before a resource is released under CC BY 4.0. Until then, this document is a licensing plan, **not a blanket grant of rights** over the repository or any existing resource.

For each approved resource, add a clear notice to the resource itself:

> © [year] [confirmed rights holder(s)]. “[resource title]” is licensed under Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/

Users should credit the named creator(s), link to the licence, link to the source when possible, and indicate whether changes were made. CC BY 4.0 allows commercial reuse and adaptation; it is not a non-commercial licence.

## Explicit exclusions

- Software and source code, including `index.html`, `app.py`, scripts and tests (no current new open-source licence granted)
- Third-party material, cited figures, images and slides, including Isabel Kemmer's presentation, unless separately authorised under their own terms
- Existing manuscripts, papers and materials whose rights have not been confirmed

For clarity, do not add a root-level `LICENSE` containing CC BY 4.0, because that could misleadingly imply the application code is licensed under CC BY.
