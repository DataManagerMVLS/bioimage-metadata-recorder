# No Cost scalable resources for Bioimage data management

**Source:** Supplied working manuscript: *No Cost resources for FAIR Bioimaging IK.docx*.

**Status:** Draft with tracked reviewer comments. This is a contextual summary, **not** the complete manuscript or a publication-ready version. Do not redistribute the original manuscript without agreement from its contributors.

## Main proposal

Scalable, no-cost approaches to recording bioimaging metadata that do not assume institutional investment in network infrastructure, dedicated research data management support or specialist programming expertise. The manuscript discusses metadata capture aligned with REMBI and preparation for BioImage Archive submission.

## Infrastructure spectrum discussed

| Infrastructure level | Illustrative approach |
|---|---|
| None | Offline spreadsheets alongside images transferred on removable media |
| Minimal | Spreadsheets adapted to Microsoft Forms; data transferred to NAS |
| Acceptable | Forms and backed-up central facility storage |
| Good | Web app and networked storage, with notifications to relevant parties |
| Excellent | Integrated storage and annotation platform, e.g. OMERO |

## Key data model

One acquisition record can be associated with **multiple analysis records** because the same image dataset may be analysed repeatedly by different researchers or methods.

## Outstanding manuscript-review points

- Avoid claims that the tools alone make datasets fully FAIR.
- Clarify distinction between capturing metadata and actually submitting data to BioImage Archive.
- Clarify versioning, corrections, dataset file lists, and links between acquisition and analysis.
- Provide evidence of adoption, real-world usage and benefits.
- Explain the pathway from spreadsheets and forms to OMERO and repository deposition.
